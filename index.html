PROJECT / 01工业视觉应用

苏盐井神安全作业 AI 智能预警系统

基于海康超脑、摄像头以及移动布控球来开发化工厂区智能安全监管系统，实现安全绳、安全帽佩戴监管、斑马线检测测、危险区域入侵检测、吊装作业风险预警以及作业票绑定管理。结合Flask+Vue+MySQL实现算法与业务平台联动，完成AI事件识别、报警记录、截图存储及语音告警闭环。

本人负责

•参与智能安全绳设备前期调研与方案选型，涉及主控板、4G 模块、压力开关、人体红外传感器开关以及电源模块；完成 MQTT 状态数据接入与监管平台联调。 •负责手机端作业票绑定功能开发，基于 Vue2 + Flask + MySQL 实现作业票、作业人员、移动布控球及安全绳设备的关联管理，并结合人脸识别完成作业人员身份核验。 •负责安全帽、未走斑马线等安全行为识别功能开发与优化，结合海康超脑智能分析、ROI区域规则及置信度阈值过滤，针对现场误报数据进行分析与模型优化。 •开发危险区域人员闯入检测算法，基于 YOLO目标检测 + ByteTrack多目标跟踪 + ROI区域判定 + 时序状态机，实现人员持续跟踪、区域入侵确认及误报警过滤。 •负责吊装作业安全检测算法开发，利用 YOLO人员检测、目标跟踪及自定义危险区域ROI，实时判断人员进入吊装禁区并联动报警、截图及事件记录。 •开发移动布控球高处作业安全绳监管算法，通过 YOLO人员检测 + ByteTrack跟踪 + 人脸身份识别 + 智能安全绳状态进行多源信息融合，实现“人员—作业票—安全绳—摄像头”关联及异常自动预警。 •参与工业现场数据采集、标注、模型训练、阈值调优及部署联调，并完成视频流处理、报警事件写库、语音告警及现场设备联动，提升复杂作业场景下算法的稳定性与实用性。

技术栈

  • YOLOv8
  • ByteTrack
  • OpenCV
  • Flask
  • Vue2
  • MySQL

PROJECT / 02智慧教育应用

智慧校园 AI 智能作业批改系统

面向中小学纸质作业自动批改场景，融合 OCR、多模态大模型、知识检索与智能体决策，实现从试卷图像识别、题目解析、答案判定到错因分析和学情反馈的自动化处理，降低人工批改与复核成本。

本人负责

• 参与设计多学科智能批改流程，基于 SubjectRouter 对数学、语文、英语、物理等学科任务进行自动路由，并根据题型选择不同解析与判题策略。

• 结合 OCR 与多模态视觉模型完成试卷版面解析、题目切分、公式识别及手写答案提取，并通过置信度判断触发视觉二次复核。

• 构建 Agent 工具调用机制，针对计算类题目调用 AST 白名单计算工具，并结合题型、OCR 结果及模型置信度动态选择处理路径。

• 引入 RAG 知识检索，融合教材知识点、标准答案和评分规则，通过 Top-K 检索辅助大模型完成答案判定、错因解释及知识点关联。

• 设计结果一致性检查、异常回退及 AgentTrace 链路追踪机制，记录模型判断、工具调用、知识召回、置信度与异常信息，提高批改结果的可解释性和系统稳定性。

技术栈

  • OCR
  • 多模态大模型
  • SubjectRouter
  • Agent
  • RAG / Top-K 检索
  • AST 白名单计算
  • AgentTrace
