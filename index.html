PROJECT / 01工业视觉应用

苏盐井神安全作业 AI 智能预警系统

基于海康超脑、摄像头以及移动布控球来开发化工厂区智能安全监管系统，实现安全绳、安全帽佩戴监管、斑马线检测测、危险区域入侵检测、吊装作业风险预警以及作业票绑定管理。结合Flask+Vue+MySQL实现算法与业务平台联动，完成AI事件识别、报警记录、截图存储及语音告警闭环。

本人负责

•手机端作业票绑定系统：基于 Vue2 开发手机端操作界面，使用 Flask 提供业务接口、MySQL存储关联数据，实现作业票、人员、移动布控球与安全绳设备绑定，并接入人脸识别进行人员与作业证身份核验，支持多类关联操作，单次绑定平均耗时5秒。

•海康平台定制算法训练与优化：针对企业现场安全帽样式多样、通行区域及作业环境复杂的特点，基于企业定制数据集，在海康开放平台开展安全帽佩戴、未按规定走斑马线及人员闯入检测算法的训练与优化；结合现场误检、漏检样例补充数据、调整阈值，并完成部署验证。

•海康 SDK 二次开发与报警接入：基于海康官方 SDK进行二次开发，接收并解析超脑上的算法报警数据，完成报警事件入库、关联图片保存与查询追溯，并联动语音告警，实现算法结果也业务平台的对接。

•服务器端视觉算法开发：使用 YOLOv8、ByteTrack、OpenCV等技术，开发卡车目标分割、智能安全绳检测及吊装作业安全检测算法，结合目标分割、人员跟踪、区域判定与设备状态信息实现风险识别，并部署至服务器运行。

•局域网音视频接入与语音对讲：基于海康 HCNetSDK 二次开发，实现局域网内设备的麦克风与摄像头调用，完成音视频采集及双向语音对讲功能，支持现场人员与管理端实时沟通。

•现场联调与部署优化：负责数据采集、标注、模型训练及阈值调优，完成视频流接入、服务器算法部署、语音告警与现场设备联动。

技术栈

  • YOLOv8
  • ByteTrack
  • OpenCV
  • Flask
  • Vue2
  • MySQL
  • 海康 SDK
  • 海康 HCNetSDK

PROJECT / 02智慧教育应用

智慧校园 AI 智能作业批改系统

面向中小学纸质作业批改场景，结合 OCR 与多模态大模型，实现题目和学生答案识别、辅助判题及批改结果展示，为教师提供批改参考。

本人负责

• 参与设计多学科智能批改流程，基于 SubjectRouter 对数学、语文、英语、物理等学科任务进行自动路由，并根据题型选择不同解析与判题策略。

• 参与作业图像识别功能开发，结合 OCR 与多模态大模型提取题目及学生答案。

• 参与自动批改流程调试，调整提示词与结果解析逻辑，完成答案判断及批改结果展示的联调。

• 整理测试样例，检查识别与批改结果，协助定位异常问题。

关键技术

  • OCR
  • 多模态大模型
  • Prompt设计
  • 模型 API 调用
